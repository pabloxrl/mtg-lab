# Independent trajectory and RL test design

Status: **design only; no implemented or executed evidence**. Independently derived from RFC 0001 (RL interoperability; Trajectories and reproducibility), RFC 0002 §8 and milestone gates, and `doc/programs/rfc-0002.json`. No sibling plans or `doc/testing` consulted. Owners below are delivery issues; M1 acceptance is #22, M3 acceptance #33, exact-release re-execution #40. Planning work does not activate future implementation issues.

## Oracle discipline

Use a handwritten canonical decision ledger, independent of engine/recorder/adapters: episode E, actors `[A,A,B,B,A,B]`, each observation marked with its seat and decision, legal candidate tables differing each decision, and terminal winner A after B's final action. All preterminal reward deltas are `(0,0)`; final delta is `(1,-1)`. A's transitions link decisions `0→1→4→final_A`; B's `2→3→5→final_B`. Terminal reward appears once in each seat's last transition. Separately author reachable game scripts against pinned rules/card definitions to confirm this synthetic contract through the real engine. Round-trip/native equivalence alone cannot establish correctness; retain handwritten ledger assertions as the independent anchor. Capture expected masks/tables before running the implementation, never regenerate goldens from it.

Framework cases must execute installed, pinned real dependencies. Cite their pinned API/source contract and upstream test version in execution receipts; mocks only support isolated fault injection. Missing packages, imports, crashes and skipped jobs cannot satisfy behavioral red evidence or compatibility. Common evidence: test ID, commit, package lock, seed/config, command, expected and actual first divergence, artifact hashes; failures redact private content.

## Concrete tests

1. **DRL-001 — Same-seat links and nonacting winner credit.** **M1 #20; M3 #28/#29.** Feed the canonical ledger through global and per-seat readers, then repeat with reversed seat labels and a draw. Assert exact links above, seat-specific final observations, monotonic global/per-seat indices, rewards `(1,-1)` or `(0,0)`, exactly one terminal credit and zero interim rewards. Repeated `last()`/reads must not consume or duplicate rewards. **Oracle:** handwritten ledger plus RFC §8 reward/trajectory clauses. **Detects:** linking next global row, alternating-seat assumptions, winner reward assigned to last actor, repeated-reader credit.

2. **DRL-002 — Three endings plus concession.** **M1 #20; M3 #29–#32.** Run the same controlled prefix to (a) rules loss, (b) concession, (c) each external decision/turn/wall-clock limit using an injected clock, (d) forced engine error/encoding overflow. Assert (a,b) terminal win/loss, (c) truncation with reason and authorized final views, (d) failed/quarantined sample excluded from training; truncation must not invent a draw. Compute a tiny value target with manually chosen final value: termination excludes bootstrap; ordinary truncation preserves eligibility under declared trainer policy; failure never bootstraps. **Oracle:** RFC reward/boundary distinction plus hand-calculated targets. **Detects:** overloaded `done`, error-to-truncation conversion.

3. **DRL-003 — Final observation survives autoreset.** **M3 #27/#29/#28.** Finish one of two slots while the other remains live; retain observation references, reset only finished slot with a visibly different hand/life marker, then export/load. Assert completed record retains old episode ID/final seat views/reward; new episode starts fresh; live slot state/history remains exact. Repeat for truncation and each documented wrapper autoreset mode. **Oracle:** handwritten two-episode ledger and RFC explicit-reset contract. **Detects:** bootstrapping from next reset, cross-slot recurrent reset.

4. **DRL-004 — Microchoices and discount time.** **M1 #20; M3 #28–#32.** Record two logical actions, first requiring three same-seat microdecisions and second ending the episode, with opponent interleaving. Assert logical-action IDs, microchoice IDs, both counts and intervening durations. With default gamma=1 all corresponding undiscounted returns match the ledger; for any supported nonunit-gamma mode calculate exponents manually in its declared unit. Missing/ambiguous discount convention must fail dataset validation for discount-dependent consumers. **Oracle:** RFC default and declared time convention, independent arithmetic. **Detects:** one discount per storage row or fragment, missing continuation time.

5. **DRL-005 — JSONL/Parquet canonical equality and replay.** **M1 #20 (JSONL); M3 #28 (Parquet).** Persist a hand-authored ledger and a rules-backed script, reload in another process, compare every required header/decision/footer field including candidate order, numeric dtype, masks, semantic action and optional nulls. Resolve the restricted replay through an authorized path and reproduce rules-backed checkpoints. Native, CLI, batched and Python collection must share schema semantics. **Oracle:** authored ledger/fixture checkpoints, not two serializers agreeing. **Detects:** lossy encodings, mask flattening, replay mistaken for safe trajectory.

6. **DRL-006 — Reused buffers cannot rewrite history.** **M1 #20; M3 #27/#28.** Queue a record with a blocked writer, overwrite all source observation/candidate/mask arrays on subsequent step/reset, then drain; also retain a Python reader batch while advancing its iterator. Assert earlier owned data remains exact or an explicitly documented invalid-lifetime access rejects, never silently changes. Recorder data must always own its snapshot. **Oracle:** original externally authored arrays and RFC copy/lifetime clause. **Detects:** asynchronous aliases, mutable optional collector metadata.

7. **DRL-007 — Version/provenance and absent policy statistics.** **M1 #20; M3 #28.** Validate a full manifest; independently remove each required version/hash/selection/reward convention, introduce incompatible schema/action version, and round-trip human/heuristic records with no log probability/value. Assert incompatibility is diagnosed or passed through an explicit tested migration; missing optional statistics remain absent, never zero/uniform guesses; behavior-probability-dependent consumers reject absent data. Check checkpoint/opponent IDs follow the actual collector and fixed episode opponent. **Oracle:** RFC schema table and explicit consumer preconditions. **Detects:** misleading off-policy eligibility, silent schema reinterpretation.

8. **DRL-008 — Cross-seat and privileged-field leakage.** **M1 #19/#20; M3 #28–#32.** Pair states with identical A-visible history but swapped B hand/library/RNG state; exercise default collector, sequence loader and model forward path. Inject distinct sentinels into B-private fields and separate privileged/replay artifacts. Assert A inputs, padding/order, masks and candidates invariant; concatenated sequences never include B observations/private final view or seeds; default loaders do not resolve opaque replay IDs. Authorized dataset inspection may reveal both seats separately and must be documented accordingly. **Oracle:** explicit visibility ledger plus RFC privacy clauses. **Detects:** joint-trajectory feature joins, metadata features, privileged critic accidentally feeding actor.

9. **DRL-009 — Mid-episode shards and recurrent sequences.** **M3 #28.** Force shard rollover and rollout fragment boundaries between A's decisions and immediately before terminal reward. Shuffle shard discovery order, load overlapping windows with burn-in and padding. Assert continuation IDs reassemble exact temporal order; no synthetic reset/truncation; terminal credit unique; episode-start and padding/loss masks correct; burn-in is explicit and never borrowed from another seat/episode. **Oracle:** handwritten ledger/windows. **Detects:** fragment treated as episode, overlap double-count, padding learning targets.

10. **DRL-010 — Interrupted atomic publication.** **M3 #28.** Kill writer at deterministic failpoints: partial record, shard flush, finalized shard before manifest publication, and manifest replacement. Reopen with default reader and diagnostic opt-in. Assert published snapshots reference only complete validated shards; earlier finalized episodes stay usable; affected fragments are identified as incomplete and excluded by default; no partial manifest is accepted. Do not require crash atomicity beyond the declared persistence contract. **Oracle:** predeclared publication state machine plus RFC finalized-shard/atomic-manifest guarantee. **Detects:** orphan treated complete, stale manifest hiding loss.

11. **DRL-011 — Corruption despite syntactic validity.** **M3 #28.** Independently flip bytes, truncate JSONL, corrupt Parquet footer, delete/duplicate a row, swap episode IDs, reorder/repeat decision indices, alter a checksum or count, and introduce footer return inconsistent with decision deltas. Some mutations deliberately receive a recomputed file checksum to test semantic validation. Assert checksum/count/schema/continuity checks reject or quarantine with specific diagnostics, never silently train on damaged episodes. **Oracle:** independent mutation inventory and ledger invariants. **Detects:** checksum-only trust, duplicate terminal credits, missing middle shards.

12. **DRL-012 — Backpressure and explicit fail mode.** **M3 #28.** Slow writer below producer throughput with a tiny bounded queue. Default mode must block, report positive queue wait and bounded memory, then persist all selected decisions exactly. Explicit overflow mode must fail clearly and mark affected episodes incomplete. Repeat ENOSPC, short write, permission error and writer-thread exception; CLI exit/collector exception and accounting must expose the failure. **Oracle:** issued record count and RFC storage failure contract. **Detects:** silent drop, success after background failure, unbounded queue.

13. **DRL-013 — Seed-based selection independent of outcomes.** **M3 #28.** Choose a declared seed-subset function; calculate selected episode IDs independently before execution. Vary worker schedule, policy outcomes, recording speed and shard size; assert the same selected set, complete selected episodes, no unselected decision materialization beyond required runtime views, and manifest rule/counts match. All-capture/off/subset preserve seeded game semantics. Outcome-triggered diagnostic capture, if added, must be labeled as biased and never advertised as this subset. **Oracle:** independent selection computation and RFC episode-start selection rule. **Detects:** worker-RNG selection, only successful games retained, recorder consuming engine RNG.

14. **DRL-014 — Scheduling and reset identity.** **M3 #27/#28.** Run a fixed seed/script set scalar, batched and with reordered worker completion, slot reuse and different shard sizes. Sort by stable episode/decision keys and compare against independently expected ledger checkpoints; ensure globally unique episode IDs across runs and both seat sequences intact. Physical row order may differ. **Oracle:** scripted ledger plus RFC reproducibility/ID contract. **Detects:** row-position identity, duplicate IDs after process restart, shared random streams.

15. **DRL-015 — Real PettingZoo AEC lifecycle.** **M3 #29.** Run pinned upstream API/seed tests and forced `[A,A,B,B,A,B]` real-engine fixture. Inspect `agent_selection`, `last()` cumulative rewards, masks, terminal flags and dead-agent cleanup calls; exactly current actor supplies a live action, both seats receive final rewards once, dead cleanup does not create policy decisions. Repeated observers do not mutate state. **Oracle:** pinned AEC source contract plus ledger. **Detects:** automatic alternation, premature global termination and cumulative-vs-instant reward confusion; upstream tests alone are insufficient.

16. **DRL-016 — Gym fixed-opponent seat semantics.** **M3 #29.** Test learner in either seat and starting-seat assignment, including several opponent actions before first learner decision and consecutive learner choices. Wrapper advances only opponent decisions, returns learner-authorized observation/reward, preserves episode-fixed opponent/version/seeds, and handles terminal-before-next-learner-action without synthetic action. Send masked-invalid, stale and wrong-seat actions through relevant underlying boundary; compare complete state/RNG/decision identity before and after rejection. **Oracle:** authored actor ledger and RFC Gym contract. **Detects:** wrong learner seat, hidden opponent reward loss, illegal-to-pass fallback.

17. **DRL-017 — Sampling and gradient-time masks.** **M3 #30/#31/#32.** Give an illegal candidate the highest raw logit, choose a legal action, persist action-time candidate table/mask, then advance to a state where candidate indices mean different actions. Sample/evaluate with zero invalid actions; recompute stored action log probability using original table/mask and compare to hand-calculated masked softmax; gradients/loss must use it too. Exercise distinct padding/legal masks and all-zero terminal mask without drawing a live action. **Oracle:** manually specified logits and masked-softmax arithmetic. **Detects:** masking only sampling, fresh-table recomputation, NaN terminal softmax.

18. **DRL-018 — RLlib real learning qualification.** **M3 #30/#33.** In an isolated pinned RLlib extra, run real `PettingZooEnv` integration (direct adapter only with recorded evidence), collect ≥1,000 decisions across multiple episodes, execute optimizer update, verify finite loss/gradients and changed trainable parameters, mask-aware evaluate, checkpoint/reload and canonical export/load. Force both seats, repeated actor, truncation and nonacting winner cases; inspect action requests and reward delivery. **Oracle:** ledger, pinned RLlib contract, independent parameter snapshots; learning improvement not required. **Detects:** wrapper import mistaken for training, two-seat simultaneous requests, omitted inactive-seat rewards.

19. **DRL-019 — TorchRL acting mask is not legality.** **M3 #31/#33.** Real pinned `PettingZooWrapper(use_mask=True)` with distinct legal sets: alternate inactive/active seats, repeat one actor, and drain dead-agent protocol while episode completion is pending. Assert acting `mask` selects rows; `action_mask` restricts logits; inactive rows never contribute actions or spurious policy loss and cannot reset live game. Perform the full ≥1,000-decision/update/evaluation/checkpoint/export qualification. **Oracle:** pinned TensorDict/wrapper contract, ledger, manual mask matrix. **Detects:** mask-name collision, reset-on-any-inactive-agent, padded-seat gradients.

20. **DRL-020 — SB3-Contrib subprocess masking.** **M3 #32/#33.** Real pinned MaskablePPO on Gym adapter for each learner seat, including subprocess environments whose masks come from environment `action_masks()`. Run ≥1,000 decisions, finite optimizer update, mask-aware evaluation, checkpoint/reload and export/load. Deliberately invalid step must strictly reject without mutation; a generic checker choosing invalid actions cannot justify coercion. **Oracle:** pinned MaskablePPO/subprocess contract plus mask arithmetic and ledger. **Detects:** parent-only mask closure, ordinary evaluation bypass, unsupported recurrent-policy claims.

21. **DRL-021 — Checkpoint and dataset equivalence across fresh process.** **M3 #30–#32.** For each real trainer save weights, preprocessing/schema/action dependencies and declared normalization/recurrent state; reload in fresh process. On frozen action-time observations/masks, deterministic evaluation logits/probabilities and chosen semantic actions agree under predeclared dtype tolerance (exact action/metadata equality); compare exported canonical reader records fieldwise. Fixed-seed compatible evaluation reproduces outcomes; unsupported checkpoint/schema versions reject. Do not demand bitwise stochastic training continuation without saved optimizer/RNG/environment state. **Oracle:** saved pre-reload outputs plus independent masked-softmax/ledger anchors. **Detects:** weights-only reload losing encoder/mask/normalization, silent action-schema drift.

22. **DRL-022 — Optional dependency isolation and truthful matrix.** **M3 #29–#33.** From clean headless environments install core and each optional trainer group independently; run actual commands with stdin closed/display unset and bounded timeout. Capture exact Python/binding/adapter/trainer/transitive locks, OS, commits, command and artifact digests. Core imports without trainers; each required integration independently passes its real training job. Dependency upgrade invalidates old verified receipt until rerun. **Oracle:** RFC compatibility acceptance and lock/install manifests. **Detects:** accidental all-trainer dependency, cached local import success, unsupported version advertised verified.

23. **DRL-023 — Shared-policy recurrent routing.** **M3 #27/#28/#29.** Use a deterministic test policy whose state accumulates seat-specific visible tokens. Interleave two games/both seats through shared inference batches, repeated same-seat actions, fragment loading and one slot reset. Compare hidden-state inputs with manually enumerated per-(episode,seat) histories; no cross-seat, cross-slot or prior-episode contamination; padding does not advance state. This routing contract does not claim recurrent MaskablePPO support. **Oracle:** explicit independent token history ledger and RFC stable identity contract. **Detects:** recurrent state keyed only by policy ID or batch row.

24. **DRL-024 — Honest collection/capture overhead.** **M3 #28/#30–#33; M5 #39.** Frozen seed/script encoded workload in capture-off, memory, JSONL and Parquet, plus each trainer's equivalent collection. Include queue draining/final publication in timing and report decisions/s, bytes/decision, writer throughput, queue wait, high-water memory, process/batch settings and native baseline. Assert semantic/count equality and no hidden failed episodes; capture-off avoids extra trajectory-only materialization via counters. **Oracle:** independent issued-decision/accounting ledger; no invented speed threshold. **Detects:** timing only enqueue, omitted encoding/inference costs, apparent speed from data loss.

## Interpretation gaps to resolve in owning issue contracts

- **Zero-action seat:** RFC requires final rewards for both seats but does not define a per-seat transition when a seat never acted. Choose an explicit episode/final record representation; never fabricate a policy action. Add this case to DRL-001/016.
- **Completion versus completeness:** a game may finish successfully while its recording fails; specify separate status fields and accounting so a completed outcome cannot validate an incomplete dataset (DRL-010/012).
- **Crash guarantees:** atomic manifest replacement alone does not specify filesystem durability, fsync/rename ordering, recovery of orphan shards or retry deduplication. Declare process-crash versus machine/power-loss support before choosing failpoints (DRL-010/011).
- **Seed metadata conflict:** RFC asks trajectories to record seeds but forbids private shuffle/RNG seeds in default features. Separate reproducibility metadata/restricted artifacts from feature-bearing fields, define permissions and seed types; do not resolve by leaking seeds or omitting provenance (DRL-007/008/013).
- **Discount duration:** counts need an unambiguous interval convention for same-seat transitions spanning continuations/opponent actions; gamma=1 hides this bug. Pin whether the source action and terminal event count and make any nonunit mode explicit (DRL-004).
- **Truncation mid-continuation:** specify authorized final observation when a multi-choice action is provisional and no ordinary next decision exists; do not expose provisional private choices or fabricate a legal live action (DRL-002/008).
- **Dataset semantic validation:** RFC explicitly requires checksums/counts; those do not catch internally consistent corruption. Define required continuity, duplicate-ID, candidate-index/mask and footer-return validation, with clear quarantine granularity (DRL-011).
- **Privacy scope:** a legitimate two-seat dataset is privileged relative to either live player. Distinguish storage access from default feature-loader isolation; shuffling rows or dropping a `private` column alone does not protect sequence joins (DRL-008/023).
- **Checkpoint equivalence:** pin tolerances and what is restored. Deterministic inference equivalence is required evidence; exact resumed stochastic optimization needs additional declared state and should not be silently promised (DRL-021).
- **Framework pins:** no versions are invented by this plan. Owners must select compatible locks and use pinned upstream APIs/tests as additional independent evidence; latest documentation is not proof for the installed version (DRL-015–022).

All tests are executable design obligations, not claims that the documented APIs already exist. First behavioral red evidence must reach the intended assertion; import failures do not count. Seed deliberate mutants (reward to current actor, next-global observation, training-time unmasked logits, buffer alias, silent writer drop, terminal-on-shard-close, opponent-feature concatenation) and demonstrate the named tests reject each before accepting the implementation.
