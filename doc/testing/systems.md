## Evidence and test conventions

IDs below are stable scenario-family IDs; parameterized instances append a descriptive suffix, not a renumbered ordinal. `S`, `A`, `E`, `O` mean setup, action, expected assertion, and independent oracle. Each table row supplies all four. Every row must become executable behavior checks, except explicitly identified architecture/documentation audits. A family cannot pass because one parameter succeeds. Mandatory supported parameters may not be skipped. `Bnnn` expands to `R0002-Bnnn` in `doc/programs/rfc-0002-requirements.json`.

Oracles: **C** = explicit RFC contract, linked by block; **H** = hand-authored expected records/checkpoints with reviewed derivation; **R** = pinned rules/card sources for game semantics; **X** = aligned independent reference execution as corroboration; **M** = metamorphic relation justified by C/R. Engine-vs-engine-path equality is valuable for integration drift but does not establish rules truth. Seeded game traces must first pass independent conformance assertions. Expected fixture data cannot be a snapshot of the implementation's output blessed after the fact. Fail an assertion for the intended behavior before implementation, preserve red/green artifacts, and keep an independently authored holdout corpus for gates.

Each result records test/variant ID, candidate commit, artifact schema and dependency versions, seed/ordered randomness, mode, expected/actual first divergence, exit status, and reproduction command. System failures retain a minimized replay and diff in restricted artifacts; public error output is redacted. General input negative cases must compare *all* semantic state including RNG, continuation, pending triggers, and decision generation, not only life totals. An error may increment diagnostic counters without mutating the game.

## Cross-cutting torture matrix and release gates

`SYS-MATRIX-001` (#37; B027/B030/B041): run core/replay/encoding/data/privacy semantic scenarios under a deliberately reviewed pairwise matrix: debug/release × scalar/native batch × native/Python encoding × workers 1/2/8 × no snapshot/pending-choice snapshot × four instrumentation modes × capture disabled/in-memory/JSONL/Parquet.
