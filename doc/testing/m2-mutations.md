# Designated M2 semantic mutation matrix

Run inside the repository's Rust/Python toolchain, from the checkout root:

```sh
python3 scripts/m2_mutations.py --output .agent-artifacts/m2-mutation-run
```

The output directory must not already exist. Managed Symphony workers wrap this
command in the shared `heavy` resource lock, as for Cargo and torture. The runner
copies tracked and nonignored source into a disposable directory under
`.agent-artifacts`, edits only that copy, and uses this checkout's
`target/m2-mutations`. It never edits production sources in the original checkout.
Run only one matrix per checkout at a time. A matrix run is additional acceptance;
it does not replace the mandatory complete `./scripts/torture.sh`.

[The executable matrix](../../fixtures/mutations/m2.json) binds twelve individual
production-source edits to exact test targets, named assertion messages, fixed
inputs and independent oracles. The tests contain no mutation switches and run
in ordinary Rust test discovery. Python discovery tests the runner's strict
classification, missing-test/build failures and anchor validation. Neither tests
nor expected outputs are generated by the engine or changed for mutants.

| Mutant | Required assertion | Independent basis |
| --- | --- | --- |
| Omitted priority | First pass gives the opponent priority in the same upkeep | CR 117.3d/117.4 |
| Stacked mana ability | One Elf tap immediately gives G with an empty stack | CR 605.3b |
| Allowed sick tap | Newly controlled Elf tap rejects without mutation | CR 302.6 |
| Missed cast trigger | Committed Growth creates one Archer trigger | CR 601.2i/603.2, pinned Archer |
| Retained boost | Grown Cub returns to 2/2 after cleanup | CR 514.2/611.2a |
| Late damage removal | Cub with Growth and 2 marked damage survives as clean 2/2 | CR 514.2/704.5g |
| Stale acceptance | Old-generation pass rejects without mutation | SYS-CORE-003 |
| Private leak | Hidden opponent hand/library swap preserves current policy input | SYS-PRIV-001 |
| Reversed reward | Lethal Cub damage credits winner +1 and loser −1 | RFC B035/B036 |
| Truncation as draw | One-keep external budget ends as truncation | RFC B035, SYS-CORE-008 |
| Clipped choices | Keep/mulligan with capacity one returns explicit overflow | RFC B016/B033, SYS-CORE-007 |
| Omitted failed denominator | Entirely failed native benchmark retains positive elapsed time | RFC B008/B019, SYS-CLI-002/PERF-001 |

Synthetic positions are explicitly test-only; they minimize a particular defect,
not prove normal-reset reachability. The normal-reset priority, opening capacity,
Driver budget and CLI cases retain seeds/configuration in test source. Existing
full-game, replay, trajectory, quantum and reference regressions remain mandatory.
The reward case reuses the existing literal combat/trajectory setup. No new
mechanics, supported cards, learning API, alternative driver or production rules
implementation is introduced.

The stacked-mana mutation incorrectly creates a nonmana-style ability object and
withholds immediate mana. Its designated checkpoint is immediately after tapping,
before resolution; it makes no claim about the mutant's later resolver. The
cleanup mutation deliberately performs a lethal-damage check between removing
the boost and removing damage. The denominator mutation drops elapsed time when
the native benchmark exits with a failure; the test induces a real owner record
capacity failure, not a fabricated benchmark row.

Each baseline must build, list exactly its designated test, and pass that one test
without ignores. Each mutant must separately build and list the same test, then
exit with Rust's test-failure status and the exact named assertion in that test's
panic. A surviving mutant, absent/mismatched test, unrelated panic, timeout,
compiler/import failure or ambiguous source anchor makes the command fail.
`receipt.json` records baseline/mutant outcomes, source hashes and test-log hashes;
separate build, discovery and test logs preserve the actual failures. A partial
receipt is not a pass. The matrix does not report a substitute aggregate percentage.

This is the bounded M2 allocation of RFC B029/SYS-MUT-001 under #213. Original
component #24 and gate #26 retain integration acceptance; later batch/IPC and
learning mutants are excluded. It does not certify whole RFC blocks or M2 itself.
No CI or verification scheduling is changed by this command.
